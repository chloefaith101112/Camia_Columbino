# Finding the Hypotenuse
## Description 
The goal for this program is to **calculate the length of the hypotenuse** which is the *longest side of a right triangle*, if the two other sides are given using the `functions from the math library, inputs, and outputs.` 

## How to Run
1. Open the .py file 

2. Run the program.

3. Enter the values for a and b.

4. Check the check the length of the hypotenuse displayed on the screen.

## Input Needed
- length of a
- length of b

## Sample Output
Enter the length of a: `6`

Enter the length of b: `8`

The length of the hypotenuse is: `10.00`
